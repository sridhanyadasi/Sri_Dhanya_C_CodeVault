# Day 6 – More Logical Programs

## Introduction

This folder contains additional logical programs in C based on arrays, strings, mathematical operations, and number properties.

These programs help improve problem-solving skills and provide practical experience with array manipulation, string handling, searching, counting, and mathematical calculations.

## Programs Covered

### 1. Find the Largest Three Numbers in an Array
Finds the three largest elements from a given array.

**Concepts:** Arrays, loops, comparisons, conditional statements.

### 2. Find Common Elements in Two Arrays
Identifies the elements that are present in both given arrays.

**Concepts:** Arrays, nested loops, element comparison, searching.

### 3. Find the Mode of a Given Set of Numbers
Finds the number that occurs most frequently in a given set of numbers.

**Concepts:** Arrays, frequency counting, nested loops, comparisons.

### 4. Merge Two Sorted Arrays
Combines two sorted arrays into a single sorted array.

**Concepts:** Arrays, two-pointer technique, comparisons, merging logic.

### 5. Find the Sum of All Even and Odd Numbers in an Array
Calculates the sum of even elements and the sum of odd elements separately.

**Concepts:** Arrays, loops, modulus operator, conditional statements, sum calculation.

### 6. Count Occurrences of an Element in an Array
Counts how many times a particular element appears in an array.

**Concepts:** Arrays, loops, searching, frequency counting.

### 7. Find the Difference Between the Sum of Squares and Square of Sums
Calculates the difference between the sum of the squares of numbers and the square of their sum.

**Concepts:** Loops, arithmetic operations, square calculation, mathematical expressions.

### 8. Reverse Words in a String (Without Using Extra Space)
Reverses the order of words in a string without using an additional string or array for storing the reversed result.

**Concepts:** Strings, character arrays, string traversal, in-place manipulation, word reversal.

### 9. Print Prime Factors of a Number
Finds and displays all prime factors of a given number.

**Concepts:** Prime numbers, factors, loops, divisibility, mathematical operations.

### 10. Find Whether a Number is a Power of Two
Checks whether a given positive number can be expressed as a power of 2.

**Concepts:** Number properties, loops, division, bitwise operators.

## Concepts Covered

- Finding largest elements in arrays
- Common elements in two arrays

- Merging sorted arrays
- Even and odd number operations
- Counting element occurrences
- Sum of squares and square of sums
- String manipulation

- Array traversal and comparison

After completing these programs, you will be able to:

- Find the largest three elements in an array.
- Compare two arrays and identify common elements.
- Find the most frequently occurring element in a set.
- Merge two sorted arrays into one sorted array.
- Calculate even and odd element sums separately.
- Count the occurrences of a particular element.
- Perform mathematical calculations using arrays and loops.
- Reverse words in a string without using extra space.
- Identify and print prime factors of a number.
- Check whether a number is a power of two.
- Improve logical thinking through practical programming problems.

## Important Points

- Array indexing starts from 0.
- The mode is the value that occurs most frequently. If multiple values have the same highest frequency, the program should define how to handle the tie.
- Both input arrays should be sorted before applying the standard two-pointer merging technique.
- Reversing words in a string is different from reversing all characters in a string.
- In-place string manipulation means modifying the original character array without creating another array to store the result.
- Prime factors must be prime numbers that divide the given number.
- A power of two is a positive number such as 1, 2, 4, 8, 16, and 32.
- Bitwise operations can be used to check whether a positive integer is a power of two.

## Purpose

The purpose of these programs is to strengthen logical thinking, improve array and string manipulation skills, and develop the ability to solve more challenging mathematical and programming problems using C.
