# Day 4 – Number System and Recursion

## Introduction

This folder contains C programs based on number system conversions, mathematical operations, and recursion.

These programs help improve logical thinking and understanding of how numbers are represented in binary form. They also introduce recursion, where a function calls itself to solve a problem.

## Programs Covered

### 1. Convert Decimal to Binary
Converts a decimal number into its binary representation.

**Concepts:** Decimal number system, binary number system, loops, modulus operator, division.

### 2. Convert Binary to Decimal
Converts a binary number into its equivalent decimal value.

**Concepts:** Binary place values, powers of 2, loops, arithmetic operations.

### 3. Find the Number of 1s in a Binary Representation
Counts how many `1` bits are present in the binary representation of a given number.

**Concepts:** Binary representation, bit checking, loops, bitwise operations.

### 4. Find the HCF and LCM of Two Numbers
Finds the Highest Common Factor (HCF) and Least Common Multiple (LCM) of two given numbers.

**Concepts:** Factors, multiples, divisibility, loops, mathematical formulas.

### 5. Count the Number of Digits in a Number
Counts the total number of digits present in a given integer.

**Concepts:** Loops, integer division, digit extraction.

### 6. Implement Binary Search Using Recursion
Searches for a given element in a sorted array by repeatedly dividing the search range into two halves using recursion.

**Concepts:** Arrays, binary search, recursion, function calls, base condition.

### 7. Implement Factorial Using Recursion
Calculates the factorial of a number by calling the same function repeatedly with a smaller value.

**Concepts:** Recursion, base condition, recursive function calls, multiplication.

### 8. Find GCD of Two Numbers Using Recursion
Finds the Greatest Common Divisor (GCD) of two numbers using recursive function calls.

**Concepts:** Recursion, Euclidean algorithm, remainder operator, base condition.

### 9. Find Power of a Number Using Recursion
Calculates the power of a number by multiplying the base repeatedly through recursive function calls.

**Concepts:** Recursion, function calls, base condition, multiplication.

### 10. Reverse a String Using Recursion
Reverses a given string by using recursive function calls.

**Concepts:** Strings, character indexing, recursion, string length, base condition.

## Concepts Covered

- Decimal and binary number systems
- Number system conversion
- Binary representation and bit counting
- HCF, LCM, and GCD
- Digit counting
- Binary search
- Recursion
- Base condition and recursive calls
- Recursive mathematical operations
- Recursive string manipulation

## Learning Outcomes

After completing these programs, you will be able to:

- Convert decimal numbers into binary and binary numbers into decimal.
- Understand binary representation and count set bits.
- Perform mathematical operations such as HCF, LCM, and GCD.
- Count the digits of a number.
- Understand and implement binary search.
- Write recursive functions to solve mathematical problems.
- Understand the importance of base conditions in recursion.
- Apply recursion to string manipulation problems.

## Important Points

- Binary numbers use only two digits: `0` and `1`.
- Each binary position represents a power of 2.
- Binary search works only on a sorted array.
- Recursion occurs when a function calls itself.
- Every recursive function must have a base condition to stop further function calls.
- HCF and GCD represent the same mathematical concept.

## Purpose

The purpose of these programs is to strengthen problem-solving skills, understand number system conversions, and develop the ability to solve problems using recursion in C.
