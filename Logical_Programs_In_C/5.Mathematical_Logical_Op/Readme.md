# Day 5 – Mathematical and Logical Operations

## Introduction

This folder contains C programs based on mathematical calculations, number properties, logical operations, and array manipulation.

These programs help improve problem-solving skills and provide practical experience with loops, conditional statements, arrays, and switch-case statements.

## Programs Covered

### 1. Find Sum of Digits of a Number
Calculates the sum of all digits present in a given number.

**Concepts:** Loops, modulus operator, integer division, digit extraction.

### 2. Check if a Number is Perfect
Checks whether a number is equal to the sum of its positive factors, excluding the number itself.

**Concepts:** Loops, factors, conditional statements, arithmetic operations.

### 3. Generate and Print Prime Numbers in a Range
Displays all prime numbers between a given starting number and ending number.

**Concepts:** Prime numbers, nested loops, conditional statements, range checking.

### 4. Find the Square Root of a Number (Without Using sqrt Function)
Calculates the square root of a given number without using the built-in `sqrt()` function.

**Concepts:** Loops, mathematical logic, approximation, floating-point operations.

### 5. Find the Sum of N Natural Numbers
Calculates the sum of the first N natural numbers.

**Concepts:** Loops, arithmetic operations, mathematical formula.

### 6. Print All Factors of a Number
Finds and displays all factors that divide a given number without leaving a remainder.

**Concepts:** Loops, modulus operator, divisibility, conditional statements.

### 7. Find the Second Largest Element in an Array
Finds the second largest element from the given array.

**Concepts:** Arrays, loops, comparisons, conditional statements.

### 8. Find the Missing Number in an Array
Identifies the missing number from an array containing a sequence of numbers with one number missing.

**Concepts:** Arrays, loops, arithmetic operations, sum calculation.

### 9. Find the Average of Numbers in an Array
Calculates the average value of all elements present in an array.

**Concepts:** Arrays, loops, sum calculation, floating-point division.

### 10. Implement a Basic Calculator Using Switch Case
Creates a basic calculator that performs arithmetic operations such as addition, subtraction, multiplication, and division based on the selected operator.

**Concepts:** Switch-case, operators, user input, arithmetic operations, conditional statements.

## Important Points

- A perfect number is equal to the sum of its positive factors, excluding itself.
- A prime number has exactly two positive factors: 1 and itself.
- The `sqrt()` function belongs to the `math.h` library, but the square root program in this folder calculates the result without using it.
- Array indexing starts from 0.
- Average calculation should use floating-point division to get decimal results.
- In a switch-case statement, `break` is generally used to prevent execution from continuing into the next case.
- Division by zero should be handled in the calculator program.
- The missing number program depends on the expected sequence and input conditions.

## Purpose

The purpose of these programs is to strengthen mathematical and logical problem-solving skills and improve the ability to apply C programming concepts to practical problems.
