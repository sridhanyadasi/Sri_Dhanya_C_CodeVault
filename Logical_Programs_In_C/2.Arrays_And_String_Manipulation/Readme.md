# Day 2 – Arrays and String Manipulation in C

## Introduction

This folder contains logical programming problems based on arrays and strings using the C programming language.

These programs help improve problem-solving skills through array traversal, searching, sorting, string manipulation, and character operations.

The programs focus on handling collections of elements and processing character sequences using loops and conditional statements.

## Programs Covered

### 1. Reverse an Array

Reverse the elements of a given array.

**Concepts:** Arrays, loops, indexing, swapping elements.

### 2. Find the Largest and Smallest Element in an Array

Find the maximum and minimum elements present in an array.

**Concepts:** Array traversal, comparison operators, conditional statements.

### 3. Sort an Array in Ascending Order

Arrange the elements of an array in ascending order.

**Concepts:** Nested loops, comparison, swapping, sorting logic.

### 4. Find the Sum of Elements in an Array

Calculate the sum of all elements present in an array.

**Concepts:** Arrays, loops, accumulator variable, arithmetic operations.

### 5. Remove Duplicates from an Array

Remove repeated elements from an array and display the unique elements.

**Concepts:** Nested loops, array traversal, element comparison, duplicate identification.

### 6. Reverse a String

Reverse the characters of a given string.

**Concepts:** Character arrays, string length, indexing, loops, swapping.

### 7. Check Whether a String Is a Palindrome

Check whether a given string reads the same forward and backward.

**Concepts:** Strings, character comparison, indexing, loops, conditional statements.

### 8. Count Vowels and Consonants in a String

Count the number of vowels and consonants present in a given string.

**Concepts:** String traversal, character comparison, conditional statements, counters.

### 9. Find the Frequency of Characters in a String

Count how many times each character occurs in a given string.

**Concepts:** Character arrays, nested loops, frequency counting, duplicate handling.

### 10. Convert Uppercase to Lowercase and Vice Versa

Convert uppercase characters into lowercase and lowercase characters into uppercase.

**Concepts:** ASCII values, character manipulation, conditional statements, loops, character functions.

## Important Points to Remember

- Array indexing starts from zero.
- Array traversal is commonly performed using loops.
- A C string must end with the null character (`'\0'`).
- `strlen()` returns the number of characters excluding the null terminator.
- Character comparison can be performed using relational operators.
- Nested loops are useful for sorting and frequency-related operations.
- Handle spaces and special characters according to the problem requirements.
- Use `<ctype.h>` functions such as `toupper()` and `tolower()` when required.
