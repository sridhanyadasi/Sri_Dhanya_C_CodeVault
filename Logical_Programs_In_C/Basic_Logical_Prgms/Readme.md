# Day 1 – Basic Logical Programs in C

## Introduction

This folder contains basic logical programming problems implemented using the C programming language.

These programs help beginners improve their logical thinking, problem-solving skills, and understanding of basic programming concepts.

The programs focus on numbers, loops, conditional statements, arithmetic operations, and mathematical logic.

## Programs Covered

### 1. Fibonacci Series

Print the Fibonacci series up to the required number of terms.

**Concepts:** Loops, variables, addition, number sequence.

### 2. Prime Number

Check whether a given number is a prime number.

**Concepts:** Loops, conditional statements, divisibility, modulus operator.

### 3. Greatest of Three Numbers

Find the greatest among three given numbers.

**Concepts:** Conditional statements, comparison operators, logical conditions.

### 4. Reverse a Number

Reverse the digits of a given number.

**Concepts:** While loop, modulus operator, division operator, digit extraction.

### 5. Palindrome Number

Check whether a given number reads the same forward and backward.

**Concepts:** Number reversal, loops, comparison operators.

### 6. Factorial of a Number

Find the factorial of a given number.

**Concepts:** Loops, multiplication, accumulator variable.

### 7. Armstrong Number

Check whether a given number is an Armstrong number.

**Concepts:** Digit extraction, loops, power calculation, arithmetic operations.

### 8. First N Prime Numbers

Print the first N prime numbers.

**Concepts:** Nested loops, prime number logic, counters, conditional statements.

### 9. Even or Odd Number

Check whether a given number is even or odd.

**Concepts:** Modulus operator, conditional statements.

### 10. Swap Two Numbers Without a Third Variable

Swap two numbers without using an additional temporary variable.

**Concepts:** Arithmetic operations, variable assignment, swapping logic.

## Concepts Covered

- Variables and data types.
- Arithmetic operators.
- Relational operators.
- Conditional statements (`if`, `if-else`).
- Loops (`for`, `while`).
- Nested loops.
- Modulus operator (`%`).
- Number manipulation.
- Basic mathematical logic.

## Learning Outcomes

After completing these programs, you will be able to:

- Understand basic number-based logical problems.
- Apply loops to solve mathematical problems.
- Use conditional statements to make decisions.
- Extract and manipulate individual digits of a number.
- Understand prime, palindrome, and Armstrong number logic.
- Develop problem-solving skills using C.

## Purpose of This Folder

This folder is part of the Day-wise Logical Programs in C collection.

Day 1 focuses on basic logical problems that help beginners build a strong foundation in programming and prepare for more challenging logical problems in the upcoming days.
