# Basic Structure Programs in C

## Introduction

This folder contains basic C programs that demonstrate how to declare structures, create structure variables, initialize structure members, and read and display student details.

## Programs Covered

### Program 1 – Structure for a Single Student

Create a structure to store a single student's ID, name, and age.

**Concepts Covered:**
- Structure declaration.
- Structure variable creation.
- Static initialization.
- Runtime input.
- Accessing members using the dot operator.
- Displaying structure data.

**Explanation:**

This program demonstrates how to store and display the details of one student using a structure.

It covers two approaches:

1. Static initialization – Assign values while declaring the structure variable.
2. Dynamic initialization – Accept values from the user during program execution.

**What to Understand:**
- Difference between structure declaration and variable declaration.
- Difference between static and runtime initialization.
- How to access structure members.
- How to read and display structure data.

### Program 2 – Structure for Multiple Students

Create separate structure variables for multiple students, such as `s1`, `s2`, and `s3`.

**Concepts Covered:**
- Multiple structure variables.
- Static initialization of multiple variables.
- Runtime input for multiple variables.
- Accessing individual student records.

**Explanation:**

This program demonstrates how the same structure can be used to store information about multiple students.

Each structure variable represents one student and stores their ID, name, and age.

**What to Understand:**
- How multiple variables can use the same structure definition.
- How each structure variable maintains separate data.
- How to read and display records individually.
- Difference between initializing multiple variables and accepting input at runtime.

## Learning Outcome

After completing these programs, you will understand:
- How to define a structure.
- How to declare structure variables.
- How to initialize structure members.
- How to read and display student information.
- How to work with multiple structure variables.

## Important Points to Remember

- A structure is a user-defined data type.
- Structure members can have different data types.
- The dot (`.`) operator is used to access structure members.
- Every structure variable maintains its own copy of the members.
- Runtime input is not the same as dynamic memory allocation.

## Purpose of This Folder

This folder helps beginners understand the basic usage of structures in C before moving to arrays of structures and functions.
