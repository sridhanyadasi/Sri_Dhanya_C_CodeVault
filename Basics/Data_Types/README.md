# C Data Types 

This repository contains simple and beginner-friendly C programs
to understand **data types** and how to print their values using
correct `printf` format specifiers.

---

## 🔹 What are Data Types?

Data types define:
- what type of value a variable can store
- how much memory is allocated
- what kind of operations can be performed

In simple words:
**Data types tell the compiler what type of data we are using.**

---

## 🔹 Why We Use Data Types?

- To store different kinds of data (numbers, characters, decimals)
- To use memory efficiently
- To avoid errors during execution
- To perform correct operations on variables

---

## 🔹 Common Data Types in C

------------------------------------------------------------------------------
| Data Type   |	Typical Size        | Description |
|-------------|---------------------|--------------|
| `int`       |2 or 4 bytes         |  Stores whole numbers |
| `float`     |4 bytes              |  Stores decimal values |
| `double`    |8 bytes              |  Stores large decimal values |
| `char`      |1 bytes              | Stores a single character |
| `short`     |2 bytes              | Stores small integer values |
| `long`      |4 or 8 bytes         | Stores large integer values |
|`long long1` |	8 bytes	            |Stores very large integer values
|`long double`|	8, 12, or 16 bytes  |	Stores higher-precision decimal values
-------------------------------------------------------------------------------

## 🔹 Note on Byte and Boolean

- C does **not** have a separate `byte` data type  
  👉 `unsigned char` is used as a byte

- C does **not** have a boolean data type  
  👉 `int` is used (`0` = false, `1` = true)
