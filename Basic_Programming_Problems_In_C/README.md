# Basic Programming Problems in C

This folder contains basic C programming problems designed to improve programming logic, conditional statements, arithmetic operations, loops, ASCII values, and switch-case concepts.

## Programs List

### 1. Check Whether a Character Is a Digit

Checks whether the entered character is a digit from `0` to `9` using ASCII values.

### 2. Check Whether a Character Is a Lowercase Letter

Checks whether the entered character is a lowercase letter from `a` to `z` using ASCII values.

### 3. Check Whether a Character Is a Vowel

Checks whether the entered character is a vowel in uppercase or lowercase using ASCII values.

### 4. Check Whether a Character Is Alphanumeric or Special

Determines whether the entered character is a letter, a digit, or a special character using ASCII values.

### 5. Swap Two Numbers Without a Temporary Variable

Swaps the values of two integer variables without using an additional temporary variable.

### 6. Count the Number of Digits

Counts the total number of digits in a given integer.

### 7. Find the First and Last Digit

Finds the first and last digits of a given integer.

### 8. Find the Sum of the First and Last Digit

Calculates the sum of the first and last digits of a given integer.

### 9. Find the Frequency of Each Digit Using Switch Case

Counts how many times each digit from `0` to `9` appears in a given integer using a switch-case statement.

### 10. Convert Days into Years, Months, Weeks, and Days

Converts a given number of days into years, months, weeks, and remaining days according to the assumptions used in the program.

Example input:

```text
Number of days: 800
```

Example output:

```text
Years: 2
Months: 2
Weeks: 1
Days: 3
```

Note: This conversion assumes 1 year = 365 days, 1 month = 30 days, and 1 week = 7 days.

## Concepts Covered

- ASCII values and character comparisons
- Conditional statements
- Arithmetic operators
- Swapping variables
- Loops and digit extraction
- Switch-case statements
- Basic mathematical calculations
- Problem-solving and logical thinking

## Purpose

The purpose of these programs is to strengthen fundamental C programming skills through practical exercises and improve the ability to solve beginner-level programming problems.

## How to Run the Programs

1. Open the required `.c` file in a C editor or IDE.
2. Compile the program using a C compiler.
3. Run the compiled program.
4. Enter the required input when prompted.
5. Observe and verify the output.

Example using GCC:

```bash
gcc Count_Digits.c -o Count_Digits
```

Run on Windows:

```bash
Count_Digits.exe
```
